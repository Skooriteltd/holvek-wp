
# Holvek - Visibility & Discovery Intelligence for WordPress


Holvek for wordpress goes beyond your regular seo-plugin to connecting your site to the holvek's discovery intelligence infrastructure that help you understand, monitor and improve how your brand is discovered across search, social media, AI answers, maps, directories and other emerging discovery surfaces. 
This enables the plugin to perform:
* discovery checks 
* AI visibility observations 
* citations 
* SERP observations 
* competitor observations 
* entity data 
* schema observations 
* indexing status 
* technical discovery signals 
* location-specific discovery 
* historical visibility 
* alerts 
* recommendations

## Positioning 
Be discoverable everywhere

## Architecture
Holvek For WordPress provides holvek's visibility and discovery intelligence inside wordpress. 


The plugin has two operating modes:
### Standalone Mode - works without a Holvek account. 
A wordpress native holvek client that provides immediate utility to the user without being connected to the holvek's api (api.holvek.com)

Free Holvek Discovery Scan which give the owner:
* basic visibility snapshot

* Google presence

* competitor comparison
* 3 major opportunities
Then a connect button to Unlock the full Discovery Intelligence report

The full seo features is documented inside
@docs/features.md

Local capabilities remain local. Cloud capabilities are additive i.e If api.holvek.com goes down, the WordPress site must continue functioning normally.

### Holvek Connected
The user optionally connects the plugin to Holvek Visibility & Discovery Intelligence API to unlocks the capabilities of Holvek's infrastructure inside wordpress. This requires the site to be authenticated on api.holvek.com. 
Connected Holvek account unlocks:
* discovery monitoring
* AI visibility
* competitor intelligence
* alerts
* recommendations
* historical intelligence

- The user initially uses the standalone version for free:

## Authentication

Connect site
→ Holvek issues a site-specific credential
→ plugin stores it securely
→ scoped permissions
→ token rotation/revocation
→ API rate limits
→ site-level identification.
